TREE HASH DEFINITION

For each package, recursively enumerate regular files and sort them by the
POSIX-form relative path using ordinal ordering. For every file append this
UTF-8/ASCII record to a SHA-256 stream:

    relative/path\0lowercase_file_sha256\n

The package digest is the lowercase SHA-256 of that stream. The digest changes
when file content or the set/name of files changes. Empty directories are not
represented. Counts and byte totals are recorded independently.
